# 033. 1단 탭 순서·이름 변경, 하위 탭 펼침 메뉴 + 정렬 선택

- 상태: decided (완료 2026-11-22)

- 관련 문서: `docs/spec/03-screens.md` 공통 레이아웃·S-16, `docs/discussions/031`·`032`

## 배경
- 사용자 요청 (2026-11-22)
  - 1단 탭 순서: **자유 게시판 / 기술 뉴스 / 보안 뉴스** ("커뮤니티" 이름을 "자유 게시판"으로)
  - 하위 탭을 토글 버튼 그룹 대신, 1단 탭에 마우스를 올리면 아래로 펼쳐지는 메뉴로
- 사용자 결정
  - 첫 주소(`/`)는 지금처럼 기술 뉴스 > 최신 (`/tech`)
  - 모바일·터치(hover 없음)는 지금 토글 버튼 그룹 유지
  - 현재 하위 탭은 목록 **우측 상단 정렬 선택**(최신순·인기순·추천순 등)으로 표시·변경

## 결정 (pm)
### 1단 탭
- 순서 `자유 게시판 · 기술 뉴스 · 보안 뉴스`. "커뮤니티" 문구는 화면 전체에서 "자유 게시판"으로 (hero 제목·문서 제목·빈 목록·로그인 안내·탈퇴 안내·개인정보 안내·등급 안내 포함)
- 주소는 그대로 (`/community/...`, `/tech/...`, `/security/...`). `/`는 `/tech` 유지

### 펼침 메뉴 (데스크톱, `lg` 이상 + hover 가능 기기)
```
 자유 게시판   기술 뉴스   보안 뉴스
              ┌──────────┐
              │ 최신      │   ← 기술 뉴스에 마우스를 올리면 펼침
              │ 추천      │   (비회원 추천 → 로그인 안내 모달, 031 그대로)
              │ 인기      │
              └──────────┘
```
- 항목: 자유 게시판 `최신·인기`, 기술 뉴스 `최신·추천·인기`, 보안 뉴스 `최신·인기`. 현재 보고 있는 항목은 선택 표시
- 1단 탭 자체를 클릭하면 그 탭의 최신으로 이동 (지금과 같음)
- 접근성: 키보드 포커스로도 펼침, ↑↓ 이동·Enter 선택·Esc 닫기, 마우스가 탭→메뉴로 내려가는 사이 닫히지 않게 짧은 지연. 메뉴는 1단 탭 아래 구분선 위에 겹쳐 뜸(본문 밀지 않음)
- 탭 이동 시 유지 규칙(분야·말머리·지역 유지, 태그·소스 초기화)은 031·032 그대로

### 정렬 선택 (데스크톱 목록 우측 상단)
- 하위 탭 토글 그룹 자리를 없애고, 목록 맨 위 줄 오른쪽에 `[최신순 ▾]` 선택 메뉴를 둠. 현재 하위 탭 = 선택된 값
  - 기술 뉴스: 최신순 · 추천순 · 인기순 / 자유 게시판: 최신순 · 인기순 / 보안 뉴스: 최신순 · 인기순
  - 바꾸면 해당 하위 탭 주소로 이동 (펼침 메뉴와 같은 동작, 비회원 추천순 → 로그인 안내)
- 인기의 기간 `[24시간 | 7일 | 30일]`은 지금 자리 그대로
- 자유 게시판 `글쓰기` 버튼은 정렬 선택 왼쪽에 나란히
- "맞춤순"(사용자별 추천 알고리즘, 보류된 개인화 작업)은 이번 범위 밖. 그 작업이 진행되면 이 정렬 선택에 항목을 추가하는 자리로 씀

### 모바일·터치 (`lg` 미만 또는 hover 불가)
- 펼침 메뉴·정렬 선택 없이 **지금 토글 버튼 그룹 그대로**

## 수용 기준
- 1단 탭 순서·이름 반영, 모든 화면에 "커뮤니티" 문구 0 (주소 제외)
- 데스크톱: 세 탭 모두 hover·키보드로 펼침, 항목 이동 정확, 정렬 선택이 현재 하위 탭과 일치하고 바꾸면 이동
- 모바일 360: 지금 토글 그룹 그대로, 가로 넘침 0. 라이트·다크 정상
- `/` → `/tech`, 옛 주소 넘김(031) 그대로
- 기존 테스트·빌드 통과
