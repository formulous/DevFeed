# 041. 검색창 디자인 개편 (커맨드 바)

- 상태: open
- 제기: pm (사용자 요청)
- 관련: client
- 관련 문서: `docs/spec/03-screens.md` 공통 레이아웃(hero 검색창, 022)·S-04, `docs/discussions/038`

## 배경
- 사용자 요청 (2026-11-24): 검색창이 예쁘지 않음. 안내 문구 "보안 뉴스 검색…"의 말줄임표도 어색함
- 사용자 결정: **커맨드 바** 느낌 (Linear·GitHub)

## 결정 (pm)
### 모양
```
기본:   ┌─────────────────────────────────────┐
        │ ⌕  보안 뉴스에서 찾기            [ / ] │   연한 회색 채움, 테두리 없음
        └─────────────────────────────────────┘
포커스: ┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
        ┃ ⌕  키보드│                  ↵ Enter ┃   표면색 배경 + 얇은 링
        ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
입력 중: 오른쪽 `/` 대신 지우기 ✕ (+ 데스크톱은 `↵` 힌트)
```
- 높이 40px(지금보다 낮게), 모서리 10px(알약형 대신), 배경 `subtle` 채움·테두리 없음, 돋보기 아이콘 16px 보조색
- 포커스: 배경 표면색 + 1px 링(강조색 아님, 기본 글자색 30% 정도) + 아주 옅은 그림자. 라이트·다크 대비 확인
- 오른쪽 `/` 키 표시(작은 키캡 모양, 데스크톱만). 입력 중엔 ✕ 지우기, 데스크톱은 `↵` 힌트를 흐리게
- **전역 단축키 `/`**: 입력창이 아닌 곳에서 `/`를 누르면 검색창 포커스 (입력·편집 중에는 동작 안 함). `Esc`는 입력 비우기 → 한 번 더 누르면 포커스 해제
- 데스크톱 폭: hero 오른쪽 최대 360px(지금보다 약간 좁게), 포커스 시 넓어지는 애니메이션 없음(레이아웃 흔들림 방지)
- 모바일: 지금 위치(헤더 아래 전체 폭), 같은 모양, 키캡·↵ 힌트 숨김

### 안내 문구 (말줄임표 없음)
| 범위 | 문구 |
|---|---|
| 기술 뉴스 | 기술 뉴스에서 찾기 |
| 보안 뉴스 | 보안 뉴스에서 찾기 |
| 자유 게시판 | 자유 게시판에서 찾기 |
- 헤더 검색 아이콘(내 정보·관리자 화면)으로 여는 검색도 같은 모양

## 수용 기준
- 1440·360, 라이트·다크에서 새 모양, 문구에 "…" 0
- `/` 단축키 포커스(입력 중 미동작), Esc 동작, 입력 중 ✕로 비우기
- 검색 동작·범위(038) 변화 없음, 가로 넘침 0, 테스트·빌드 통과
