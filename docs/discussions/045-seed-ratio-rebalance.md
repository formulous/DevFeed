  - 방식: 글 추가 + 기존 댓글 축소

  - 목표 글 수: 약 150개

## 작업 1 — 기존 글 축소 (`045-seed-trim.json`)
- `deleteCommentIds` 170건 삭제
  - 기존 글 32개 기준, 남기는 댓글은 `keepCommentIds`에 적음
  - 채택 댓글 12개는 모두 남김. 답글은 부모를 남긴 경우만 남김
- 삭제 방식은 dba가 정함 (하드 삭제 권장, 시드 데이터라 "삭제된 댓글" 흔적이 남지 않게 함)
  - 관련 행(답글·신고·점수 원장 `score_events`·카운터)이 같이 정리되어야 함
- 좋아요: 글마다 `likesAfter`가 될 때까지 기존 좋아요 행을 무작위로 지움. 받은 좋아요 점수도 같이 회수
- 삭제 대상 댓글이 지금 DB에서 바뀌었으면(실사용자 댓글 등) 그 행은 건드리지 않고 기록함

## 작업 2 — 새 글 120개 삽입 (`045-seed-new-posts.json`)
- 항목: `author`(시드 닉네임) · `category` · `tags`(태그 이름) · `title` · `body`(마크다운) · `publishedAt`(UTC) · `comments[]`(`key`·`author`·`content`·`createdAt`·`replyTo`?) · `accept`?(댓글 key) · `likers[]`(닉네임)
- 작성일은 2026-10-26 ~ 2026-11-22 사이에 흩어져 있음. 댓글은 글 작성 뒤 시각임
- 시드 계정(user id 22~41) 가입일이 2026-11-22라 글보다 늦음
  - 시드 계정 `created_at`을 가장 이른 글보다 앞(예: 2026-10-20 무렵, 계정마다 조금씩 다르게)으로 당겨 맞춤
- 글 하나 넣을 때 맞춰야 할 것 (기존 커뮤니티 글 생성 경로와 같은 상태)
  - `posts`(kind COMMUNITY, source 81)·`community_posts`·태그 연결
  - 요약 `summary`, 검색 색인 `community_search`(본문 앞 2,000자)
  - 댓글·답글, 채택(`acceptedCommentId`·solved)
  - 좋아요, 조회수(작은 무작위 값, 좋아요·댓글보다 크게)
  - 카운터
- 점수 원장: 글 +10(하루 3개분까지), 받은 좋아요 +1(하루 50 한도), 댓글 점수 등 기존 규칙대로 시각에 맞춰 적립. 등급이 규칙대로 계산되게 함
- 작성 제한(24시간·하루 5개·60초)은 API 경로가 아니라 해당 없음. 다만 같은 작성자의 하루 글 수는 실제로 5개를 넘지 않음
