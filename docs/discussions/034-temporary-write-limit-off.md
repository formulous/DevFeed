# 034. 시연 데이터용 글쓰기 24시간 제한 임시 해제

- 상태: open
- 제기: pm (사용자 요청)
- 관련: server, dba
- 관련 문서: `docs/discussions/032-community-board.md` F-092 작성 제한

## 배경
- 사용자 요청 (2026-11-22): 글쓰기 24시간 제약을 임시로 없애고, 임시 회원 약 20개로 기술 게시글 약 30개 + 글당 댓글 1~30개 생성
- 032 시연 데이터 1일차(임시 계정 6개)에 이어 진행. 계정은 14개 추가해 총 20개

## 결정 (pm)
- **server: 가입 24시간 제한(`NEW_ACCOUNT`)만 임시로 끔.** 하루 5개·60초 간격·댓글 속도 제한(1분 5개)은 그대로 둠 (시연 스크립트가 맞춰 씀)
  - 방식은 server 재량 (설정 값 기본을 바꿔 배포하거나 플래그). `.env` 수정이 필요하면 pm에게 알려 주면 사용자에게 요청함
  - `write-status`도 같은 계산이어야 함 (화면 안내가 어긋나지 않게)
- 시연 데이터 생성이 끝나면 pm이 알림 → **server가 24시간 제한을 원래대로 복구** 후 배포. 복구 확인 후 종결
- 데이터 생성은 pm이 공개 API로만 함 (점수·카운터·정합성은 일반 사용 경로 그대로)
  - 계정 이메일 `devfeed.seedNN@example.com`, 접속 정보는 저장소 밖 pm 작업 폴더에만
- dba: 생성 후 정합성 재검사

## 수용 기준
- 해제 중: 가입 직후 계정 `write-status.allowed = true`, 글 작성 201
- 복구 후: 가입 직후 계정 `reason = NEW_ACCOUNT`, 글 작성 429
- 생성 데이터 정합성 검사 0
