# 042. 목록 상단 "이번 주 인기" TOP 3

- 상태: open
- 제기: pm (사용자 요청)
- 관련: server, client, dba
- 관련 문서: `docs/spec/03-screens.md` S-01·S-14·S-16, `docs/discussions/035`(댓글순·좋아요순)

## 배경
- 사용자 요청 (2026-11-24): 좋아요·댓글 수 기준으로 목록 상단에 TOP 3~5 인기글을 알아보기 쉽게 표시
- 사용자 결정: **세 탭 모두**(자유 게시판·기술 뉴스·보안 뉴스), 모양은 **순위 배지 카드 줄**

## 결정 (pm)
### 기준 (server)
- 대상: 최근 7일 발행 글, 점수 = **좋아요 수 + 댓글 수**, 점수 1 이상, 상위 **3건**. 동점은 댓글 수 → 최신 발행순. 최대 10분 지연(캐시) 허용
- 범위: 자유 게시판 `VISIBLE`만, 기술 뉴스 블로그 글만, 보안 뉴스 보안 글만 (서로 섞이지 않음)
- 현재 필터 반영: 기술 뉴스 분야(`field`), 자유 게시판 말머리(`category`), 보안 뉴스 지역(`region`). 태그·소스 필터는 반영하지 않음(상위 3건이 거의 비게 됨)
- 3건 미만이면 있는 만큼, 0건이면 영역 자체를 숨김 (보안 뉴스는 반응이 적어 자주 숨겨질 수 있음 — 허용)
- API 형태(기존 인기 경로에 `sort=REACTIONS&size=3` 또는 새 경로)는 server 재량. dba는 쿼리가 기존 인덱스로 충분한지 확인 (035와 같은 형태라 마이그레이션 없을 것으로 예상)

- 위치: 각 탭 **최신순 목록 맨 위**(정렬 글자 탭 아래, 첫 글 위). 인기·댓글·좋아요·추천순 화면에는 넣지 않음(이미 순위 목록)
- 데스크톱: 3칸 가로 카드, 연한 배경(`subtle`)으로 목록과 구분, 큰 순위 숫자. 1위만 강조색
- 모바일: 세로 3줄 압축형(순위 숫자 + 제목 1줄 + ♡·💬), 같은 배경 박스
- 카드 클릭: 자유 게시판은 상세, 기술·보안 뉴스는 지금 목록과 같이 원문 새 탭 + 조회 기록
- 머리말 `🔥` 대신 아이콘 컴포넌트(불꽃 또는 트렌드)를 써도 됨. "더 보기 ›": 자유 게시판 → 좋아요순 7일, 기술 뉴스 → 댓글순 7일, 보안 뉴스 → 인기순 7일
- 같은 글이 아래 최신 목록에도 나오는 것은 허용 (중복 제거 안 함)
- 로딩 중엔 3칸 스켈레톤, 실패하면 영역 숨김(목록은 그대로)

## 수용 기준
- 세 탭 최신순에서 TOP 영역 표시, 점수 순서·필터 반영, 0건이면 숨김, 범위 간 섞임 0
- 1440 3칸·360 세로, 라이트·다크 정상, 가로 넘침 0, 목록 첫 화면 로딩 지연 체감 없음(API p95 300ms 이하)
- 테스트·빌드 통과
