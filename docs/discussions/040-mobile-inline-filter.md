# 040. 모바일 필터를 다이얼로그 대신 페이지 안 펼침으로

- 상태: open
- 제기: pm (사용자 요청)
- 관련: client
- 관련 문서: `docs/spec/03-screens.md` S-12·S-14·S-04, `docs/discussions/017`(필터 선택 창), `039`(모바일 시트)

## 배경
- 사용자 요청 (2026-11-24): 모바일에서 필터를 고를 때 다이얼로그(039 하단 시트)로 뜨는 게 보기 힘듦. 다이얼로그로 안 뜨게
- 사용자 결정: **페이지 안에서 펼침** — `[태그 ▾]`를 누르면 버튼 줄 바로 아래에 패널이 펼쳐지고 글 목록은 아래로 밀림

## 결정 (pm)
### 대상 (모바일 `lg` 미만만, 데스크톱 사이드바·선택 창은 그대로)
- 기술 뉴스 최신·인기: `[태그 ▾] [유형 ▾] [소스 ▾]`
- 보안 뉴스: `[출처 ▾]`
- 검색 결과: 범위별 필터 버튼 (기술 태그·소스, 보안 지역, 자유 게시판 말머리 등 지금 모바일에서 창으로 뜨는 것 전부)
- 북마크 등 같은 필터 컴포넌트를 쓰는 화면 동일

### 펼침 패널
```
[태그 ▴] [유형 ▾] [소스 ▾]          ← 누른 버튼 ▴, 선택 수 배지 (태그 2)
┌──────────────────────────────┐
│ [태그 검색...............]     │
│ Java✓  React  Kafka  Spring   │  ← 기본: 자주 쓰는 20개
│ Redis  AWS  ...               │
│                     더 보기 ›  │  ← 같은 패널 안에서 전체 목록 + 분류 탭으로 늘어남
│ 선택 1/10 · 초기화      접기 ▴ │
└──────────────────────────────┘
(글 목록)
```
- 한 번에 패널 하나만 열림 (다른 버튼 누르면 앞 패널 접힘)
- **칩을 누르면 바로 적용** (적용 버튼 없음). 연속 탭에 요청이 몰리지 않게 300ms 모아서 반영, 주소 쿼리 동기화
- 선택 한도·검색·분류는 지금 선택 창과 같음 (태그 10개, 소스 20개). 한도 넘으면 칩 비활성 + 안내 한 줄
- "더 보기"로 늘어난 패널은 최대 높이 60dvh 안에서 패널 안만 스크롤. 페이지 스크롤과 겹치지 않게 함
- 접기: 같은 버튼 다시 누르기, `접기 ▴`, 목록 쪽으로 스크롤해 패널이 화면 밖으로 나가도 열린 채 유지(다시 올라오면 그대로)
- 선택된 항목은 버튼 줄 아래 선택 칩 줄(`Java ✕`)로 접힌 상태에서도 보임 (지금과 같으면 유지)
- 키보드·스크린리더: 버튼 `aria-expanded`·`aria-controls`, 패널은 일반 영역(포커스 가두지 않음)

## 수용 기준
- 360·390에서 필터 버튼을 눌러도 다이얼로그·시트가 뜨지 않고 페이지 안에 패널이 펼쳐짐, 목록이 아래로 밀림
- 칩 선택 즉시 목록·주소 반영, 한 번에 패널 하나, 더 보기·검색·초기화 동작
- 데스크톱 필터 화면 변화 없음, 라이트·다크 정상, 가로 넘침 0, 테스트·빌드 통과
