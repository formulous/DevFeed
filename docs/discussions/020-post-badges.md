# 020. 글 카드 배지: NEW·인기

- 상태: decided
- 제기: pm (사용자 요청)
- 관련: server, client
- 관련 문서: `docs/spec/02-features.md` F-014·F-013, `docs/spec/03-screens.md` 글 카드, `docs/api/openapi.yaml` `PostSummary`

## 배경
- 사용자 피드백 (2026-11-20): 피드 화면이 밋밋함. 최신 글이나 조회 인기 글에 심플한 표시를 붙이고 싶음
- 지금 글 카드는 소스·상대 시간·제목·요약·태그만 있어 새 글과 많이 읽힌 글이 구분되지 않음

## 결정 (pm)
- 글 카드 제목 앞(또는 소스 줄 오른쪽)에 작은 텍스트 배지 최대 2개: `NEW`, `인기`
  - `NEW`: `publishedAt`이 현재 기준 24시간 이내. client가 계산 (API 변경 없음)
  - `인기`: 최근 7일 인기 글 상위 20건(F-013 7일 기준과 같음, 조회수 1 이상)에 드는 글
    - server가 `PostSummary.isPopular: boolean`(필수) 추가. F-013 인기 글 캐시(10분)를 그대로 써서 id 집합 포함 여부만 판정, 추가 쿼리 없음
    - 최대 10분 지연 허용
  - 둘 다 해당하면 `NEW` `인기` 순으로 둘 다 표시
- 디자인: 심플하게
  - 작은 알약형 텍스트 배지(글자 11~12px, 좌우 6px), 아이콘·애니메이션 없음
  - `NEW` = 주 색상 옅은 배경, `인기` = 주황 계열 옅은 배경. 다크 모드에서도 대비 확보
  - onyx-ui에 배지 컴포넌트가 있으면 재사용, 없으면 client에서 작게 구현 (onyx-ui 수정 필요하면 별도 승인)
  - 스크린리더: 배지는 텍스트 그대로 읽힘 ("NEW", "인기")
- 적용 화면: 글 카드를 쓰는 모든 곳 — S-01 홈, S-02 추천, S-04 검색, S-08 북마크
  - S-03 인기 화면은 순위·조회수가 이미 있으므로 `인기` 배지 생략, `NEW`만 표시
  - S-09 읽은 기록(컴팩트 카드)은 표시하지 않음
- 근거: 시각 요소를 늘리되 정보가 있는 표시만 추가. `NEW`는 계산만으로 가능, `인기`는 이미 있는 캐시 재사용이라 비용 작음

## 수용 기준
- 24시간 이내 발행 글에 `NEW`, 25시간 전 글에는 없음
- 7일 인기 상위 20건 글에만 `인기` 배지, 그 외·조회수 0 글에는 없음
- 한 카드 배지 최대 2개, 360px에서 제목 줄 넘침·겹침 없음
- `isPopular` 필드가 없으면(구버전 응답) `인기` 배지만 생략하고 정상 렌더링
