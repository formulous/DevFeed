## 1. 사이드바 스크롤 (사용자 제보, 버그)

### 현상
- S-01·S-04 좌측 필터 카드(태그 / 소스 유형 / 소스)에서 "더보기"를 누르면 카드가 계속 길어짐
- 스크롤은 본문(피드)에만 생기고, 사이드바는 화면 밖으로 넘어간 부분을 볼 방법이 없음 (사이드바가 화면에 고정돼 있고 자체 스크롤이 없는 상태로 추정)

### 결정 (pm)
- 사이드바를 **본문과 독립적으로 스크롤되는 고정 패널**로 바꿈
  - 데스크톱(`lg` 이상): 사이드바 `position: sticky`, `top` = 헤더 높이 + 여백, `max-height: calc(100vh - top - 하단 여백)`, `overflow-y: auto`
  - 사이드바 스크롤이 끝까지 가도 본문이 따라 스크롤되지 않게 `overscroll-behavior: contain`
- 섹션별 펼침 높이 제한: 태그·소스 목록은 "더보기"로 펼쳐도 섹션 안 최대 약 12줄(대략 `max-height: 18rem`)까지만 늘어나고 그 안에서 스크롤
  - 섹션 상단의 검색 입력(03 와이어프레임 `[검색 태그..]`, `[검색 소스..]`)으로 바로 찾는 흐름을 주 경로로 둠
  - 선택된 항목은 펼침 여부와 관계없이 섹션 상단에 먼저 표시 (스크롤 안에 숨지 않게)
- 모바일 드로어(`lg` 미만): 드로어 본문도 같은 규칙. 드로어 높이 100% 안에서 스크롤, 하단 "적용/초기화" 버튼은 고정
- 수용 기준
  - 1280×720 화면에서 태그·소스 "더보기"를 모두 펼쳐도 사이드바 모든 항목에 스크롤로 도달 가능
  - 사이드바 스크롤과 피드 무한 스크롤이 서로 간섭하지 않음
  - 360px 드로어에서 같은 조건 충족
  - Playwright 캡처(`npm run capture`)에 "더보기 펼친 상태" 캡처 추가해 확인

## 2. 좌우 광고 영역 (사용자 요청, 신규 기능)

### 방향 (pm)
- 기존 formulous 도구(`salary_calc`)와 같은 방식 재사용: 좌우 세로 광고(160×600) `SideAd`, 화면 폭이 충분할 때만 표시
- 배치
  - 1440px 이상: `[좌 광고 160] [필터 사이드바] [피드] [우 광고 160]`. 광고는 `sticky`
  - 1440px 미만: 광고 숨김 (필터 사이드바·본문 폭을 줄이지 않음)
- 표시 화면: 공개 콘텐츠 화면만 — S-01 홈, S-02 추천, S-03 인기, S-04 검색
- 표시하지 않는 화면: 로그인·가입·온보딩(S-05~S-07), 내 정보(S-08~S-10), 개인정보 안내(S-11), 관리자(A-01~A-04)
  - 로그인·관리자 화면 광고는 사용성과 광고 정책 측면에서 부적절
- 광고 스크립트(`adsbygoogle.js`)는 광고가 있는 화면에서만 1회 로드, 로드 실패·광고 차단 시 빈 영역 없이 레이아웃 유지
- S-11 개인정보 안내에 Google 광고 쿠키 사용 문구 추가 (formulous 허브 `privacy` 문구와 맞춤)
- `ads.txt`는 formulous.org 루트에 이미 있음 (`pub-1750461537555326`) → 추가 작업 없음

### 사용자 확인 필요 (착수 전)
- 광고 단위(slot) ID: 좌·우 각각 새로 만들지, `salary_calc`의 기존 단위(`7771869066`, `6267215701`)를 재사용할지
- 표시 화면 범위 확인 (위 4개 화면)
- `noindex` 유지 여부: 광고 게재 자체는 가능하지만, 검색 노출이 없으면 유입이 적음
