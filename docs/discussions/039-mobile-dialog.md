# 039. 모바일 다이얼로그 여백·크기 개선

- 상태: open
- 제기: pm (사용자 요청)
- 관련: client
- 관련 문서: `client/src/components/common/Modal.tsx`, `ChipPickerModal`, `GradeGuideModal`, `ReportModal`, `ConfirmModal`, `LoginPromptProvider`, `TagFormModal`, 설정 관심 태그, `docs/spec/03-screens.md` 공통 레이아웃·S-12

## 배경
- 사용자 요청 (2026-11-24): 모바일에서 다이얼로그가 화면에 너무 꽉 참. 모바일에서도 정상적으로 보이게
- pm 확인 (360×740, 공개 사이트)
  - 태그·소스 선택 창(S-12): **화면 전체(360×740)를 덮음**. 뒤 배경·둥근 모서리·위 여백 없이 페이지처럼 보여 다이얼로그인지 알기 어려움
  - 등급 안내(030): 328×608로 위아래 16px만 남음
  - 로그인 안내: 좌우 16px 여백, 화면 가장자리에 붙어 보임

## 결정 (pm)
### 모바일(`sm` 640px 미만) 두 가지 형태
| 형태 | 대상 | 모양 |
|---|---|---|
| **가운데 작은 창** | 짧은 안내·확인: 로그인 안내, 확인(삭제·탈퇴 등), 신고 | 좌우 여백 **24px**(최대 폭 320px), 둥근 모서리 유지, 세로 가운데. 내용이 길어지면 본문만 스크롤 |
| **아래에서 올라오는 시트** | 내용이 긴 창: 태그·소스 선택(S-12), 등급 안내, 관심 태그 편집, 관리자 태그 폼 | 화면 아래에 붙고 **최대 높이 85dvh**(위로 배경이 최소 15% 보임), **위쪽 모서리만 둥글게(16px)**, 맨 위 손잡이 막대, 제목·닫기 고정, 본문만 스크롤, 하단 버튼 줄 고정 + 아이폰 하단 안전 영역(`env(safe-area-inset-bottom)`) 여백 |
- 공통: 뒤 배경 어둡게 + 배경 눌러 닫기·Esc 닫기 유지, 열린 동안 뒤 페이지 스크롤 잠금, 입력창 포커스 때 키보드가 올라와도 버튼이 가려지지 않게(`dvh` 기준)
- 시트 손잡이를 아래로 끌어 닫기는 있으면 좋지만 필수 아님 (닫기 버튼·배경 누르기로 충분)
- 열림·닫힘 애니메이션: 시트는 아래에서 올라오기 150~200ms, 가운데 창은 지금처럼. `prefers-reduced-motion`이면 생략
- 데스크톱(`sm` 이상)은 지금 그대로

## 수용 기준
- 360×640·360×740·390×844에서 모든 다이얼로그가 화면 가장자리에 붙지 않음(가운데 창 좌우 24px, 시트 위로 배경 15% 이상)
- 시트의 하단 버튼·닫기 버튼이 항상 보이고 본문만 스크롤
- 라이트·다크 정상, 가로 넘침 0, 데스크톱 모양 변화 없음, 테스트·빌드 통과
