# 046. 시드 활동 시각 자연스럽게 재배치

- 상태: decided
- 제기: pm (사용자 요청)
- 관련: dba
- 관련 문서: 034, 045

## 배경
- 사용자 (2026-11-24): "게시글 댓글 입력시간이 좀 부자연스러운데 수면시간 외 꾸준히 활동이 있었다는 기준으로 시간 변경좀 해줘"
  - 운영 DB 시각 변경을 사용자가 직접 지시함
- 공개 API 기준 지금 분포
  - 자유 게시판 댓글 97건 중 51건이 2026-11-22에 몰려 있음. 그중 47건이 KST 23시
  - 새벽 1~7시 댓글이 13건 있음
  - 기존 시드 글 32개는 2026-11-22 저녁 몇 시간 안에 몰려 있음 (API 일괄 작성 흔적)

## 대상
- 시드 계정(user id 22~41)이 만든 모든 활동의 시각
  - 자유 게시판 글: `published_at`과 그에 딸린 생성 시각 컬럼
  - 댓글·답글: 자유 게시판, 기술·보안 뉴스 모두 포함
  - 좋아요, 채택 시각(컬럼이 있으면)
  - 이 활동에서 나온 점수 원장 `score_events`
- 실사용자(id 21 등)와 운영자(id 5)의 행은 바꾸지 않음
- 시드 글에 실사용자가 단 댓글이 있으면 그 댓글 시각이 기준임. 시드 글 시각은 그 댓글보다 앞이어야 함

## 시각 규칙 (모두 KST)
1. **기간**: 2026-10-26 08:00 ~ 적용 시각 −1시간. 미래 시각 0건
2. **수면 시간 제외**
   - 기본은 01:30~07:30에 활동 없음
   - 사람마다 조금씩 다르게: 계정별 취침 00:30~02:00, 기상 07:00~08:30
   - `인프라야간조`만 취침 03:00, 기상 10:00
3. **꾸준함**
   - 시드 글 152개를 기간 전체 날짜에 고르게 나눔 (하루 4~7개, 주말은 조금 적게)
   - 하루 안 분포: 점심(12~13시)과 저녁(20~24시)에 많이, 출근 시간(9~11시)에 중간 정도, 업무 오후는 적게
   - 같은 작성자 글 간격은 최소 3시간, 하루 글 3개 이하
4. **이번 주 인기 유지**: 지금 댓글·좋아요가 가장 많은 기존 글 상위 10개 중 5개는 최근 7일 안에 둠. "이번 주 인기"가 비지 않게 하기 위함
5. **댓글**
   - 글 작성 뒤 5분~48시간. 대부분 6시간 안이고, 길게 늘어지는 분포로 둠
   - 작성자 수면 시간에 걸리면 다음 기상 이후로 밀어냄
   - 답글은 부모 댓글 뒤 5분~12시간
   - 채택은 채택 댓글 뒤
   - 같은 작성자 활동 간격은 최소 2분
6. **좋아요**: 글 작성 뒤 ~ 기간 끝 사이에서 같은 규칙(수면 제외)
7. **순서 보존**
   - 같은 글 안 댓글 순서는 지금 순서를 유지함 (대화 흐름 때문)
   - 글 간 상대 순서는 바뀌어도 됨
8. **기술·보안 뉴스 댓글**: 해당 기사 발행 시각 뒤, 위 규칙 4~5 적용
9. **계정 가입일**: 그 계정 첫 활동보다 앞. 지금 2026-10-19~21 값을 유지하거나 필요한 만큼 당김

## 같이 맞출 것
- 점수 원장을 새 시각 기준으로 다시 적립함
  - KST 하루 한도(글 3개분, 댓글 10개분, 받은 좋아요 50점)
  - `users.score`와 등급을 재계산함
- 인기·이번 주 TOP 3 집계 캐시가 있으면 갱신함. 없으면 server 캐시 만료(최대 10분)를 기다림
- `updated_at`·`edited_at`은 건드리지 않음 (null이면 null 유지)
