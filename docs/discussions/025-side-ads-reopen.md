## 배경
- 016(2026-11-20)에서 사용자 결정으로 광고 제외, 코드 전부 제거
- 사용자 재요청 (2026-11-21): "페이지 양 사이드에 구글 애드센스 광고 붙여줘"
- pm이 016 제외 근거(스크랩·가치 낮은 콘텐츠 정책 위험, 게시자 ID 공유로 다른 도구까지 제재 확산 가능, 상업성 증가)를 다시 안내함 → 사용자 결정: **위험 감수하고 붙임**, 기존 게시자 ID·광고 단위 그대로 사용

## 결정 (pm)
- 016 2번 설계를 기준으로 재구현. 022·023 이후 화면 구조에 맞춤
- 광고 계정
  - 게시자 `ca-pub-1750461537555326`, 메타 `<meta name="google-adsense-account" content="ca-pub-1750461537555326">`
  - 좌 `devfeed-left` `3021654585`, 우 `devfeed-right` `2195210969` (반응형 디스플레이, `data-ad-format="auto"`, `data-full-width-responsive="true"`)
  - `ads.txt`는 formulous.org 루트에 이미 있음 → 추가 작업 없음
- 배치
  - 1440px 이상: `[좌 광고 160] [본문 영역(사이드바+피드)] [우 광고 160]`, 광고는 `sticky`(헤더 아래). 폭 160px 고정 컨테이너로 세로형 유도
  - 1440px 미만: 광고 숨김, 기존 레이아웃 그대로
  - 본문 영역 축소 허용 (016 사용자 결정 유지)
- 표시 화면: 공개 콘텐츠 화면만 — 최신(S-01), 추천(S-02), 인기(S-03), 보안 뉴스(S-14), 검색(S-04)
- 표시하지 않는 화면: 로그인·가입·온보딩(S-05~S-07), 내 정보(S-08~S-10), 개인정보 안내(S-11), 관리자(A-01~A-04), 404
- 로딩
  - `adsbygoogle.js`는 광고 화면 첫 진입 시 1회 동적 로드, 화면 이동 때 중복 로드 없음
  - `ins` + `push({})`는 광고 컴포넌트 마운트 시 1회. SPA 탭 이동 시 같은 `ins`에 다시 push하지 않음(콘솔 오류 방지)
  - 로드 실패·광고 차단·미게재 시 빈 회색 상자 없이 영역만 비거나 접힘, 본문 레이아웃 흔들림 없음
- 테마(022): 광고 영역 바깥 컨테이너는 테마 토큰 배경, 광고 자체 색은 손대지 않음
- S-11 개인정보 안내에 문구 추가 (해요체, 024): "Google 광고를 보여주기 위해 Google과 파트너가 쿠키를 사용할 수 있어요. 맞춤 광고는 Google 광고 설정에서 끌 수 있어요." + Google 광고 정책 링크
- 위험 완화(기본 적용, 추가 비용 낮음)
  - 광고는 좌우 2개만. 본문 사이(피드 중간) 광고, 자동 광고 사용 안 함
  - 글 요약 길이·원문 링크 우선 노출 현행 유지

## 수용 기준
- 1440×900·1920×1080: 공개 콘텐츠 5개 화면에 좌우 광고 영역 표시, 스크롤해도 헤더 아래 고정
- 1280×800·360px: 광고 영역·스크립트 요청 0건
- 비표시 화면 직접 진입 시 광고 영역 0개 (스크립트는 이전 화면에서 로드됐을 수 있음, 허용)
- 탭 5개를 오가도 `adsbygoogle.js` 요청 1회, 콘솔에 `adsbygoogle.push() error` 0건
- 광고 차단 환경에서 레이아웃 깨짐 없음
- 라이트·다크 테마 모두 확인
- `build:web` 결과에 게시자 ID 메타·광고 단위 ID 포함

## 의견

### client (구현·배포, 2026-11-21)
- 구현: `SideAd`(160px 고정 폭, `sticky` 헤더 아래 24px, 테마 `bg-app`) + `lib/ads.ts`(스크립트 1회 로더, `ins`별 `push` 1회, 1440px `matchMedia`). `AppLayout`에서 히어로가 있는 화면(최신·추천·인기·보안 뉴스·검색)만 `main` 좌우에 그림. 탭 이동 때 `AppLayout`이 유지돼 `ins`를 다시 만들거나 push하지 않음
  - 미게재는 `ins[data-ad-status=unfilled]` 숨김, 차단 시 높이 0 → 빈 회색 상자 없음. 광고 폭만큼 본문이 줄어듦 (1440px에서 본문 약 1040px)
  - `index.html` 메타 `google-adsense-account`, S-11에 "광고 쿠키" 항목(지정 문구) + Google 광고 정책·광고 설정 링크
- 테스트: `tests/ads.test.tsx` 13건 (5개 화면 표시·슬롯 ID, 1440 미만 0건·스크립트 0, 비표시 6개 화면 0건, 탭·검색 이동 시 스크립트 1·push 2). 전체 126건 통과
- 실서버 확인 (Playwright, formulous.org)
  - 1440×900 라이트·1920×1080 다크: 5개 화면 좌우 광고 영역 2개, 스크롤 후 top 81px 고정, 가로 넘침 0
  - SPA 탭 4회 이동: `adsbygoogle.js` 요청 1회, 콘솔 AdSense 오류·경고 0
  - 1280×800·360px: 광고 영역·스크립트 요청 0. `/login`·`/privacy`·404: 광고 영역 0
  - 광고 차단(googlesyndication abort): 레이아웃 변화 없음, 영역 높이 0
  - `dist-web`에 게시자 ID 메타·슬롯 ID 2개 포함
- 현재 두 단위 모두 `data-ad-status="unfilled"` → 화면에는 아무것도 안 보임. 사이트(`formulous.org/portfolio`) 승인·광고 단위 활성 대기로 보임. AdSense 콘솔에서 확인 필요 (사용자)
  - Google이 넣는 숨김 `ins.adsbygoogle-noablate`(display:none)는 기본 동작이라 둠. 콘솔에서 **자동 광고가 켜져 있으면** 피드 중간·앵커 광고가 생길 수 있으니 이 사이트는 꺼 둘 것 (025 위험 완화)
