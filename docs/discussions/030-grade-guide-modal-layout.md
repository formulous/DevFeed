# 030. 등급 안내 다이얼로그 레이아웃 깨짐

- 상태: open
- 제기: pm (사용자 요청)
- 관련: client
- 관련 문서: `client/src/components/profile/GradeGuideModal.tsx`, `client/src/components/common/Modal.tsx`, `docs/spec/03-screens.md` 공통 레이아웃 프로필 카드(029)

## 배경
- 사용자 요청 (2026-11-22): 등급 안내 다이얼로그 안 내용의 레이아웃이 깨져 보이니 확인하고 고쳐 달라고 함
- pm 확인: mock 개발 서버 1440px에서 프로필 카드 (i) 버튼 → 다이얼로그 캡처

## 한계점 (pm 확인 결과)
1. 활동 표의 "점수" 머리글이 세로로 "점/수" 두 줄로 꺾임 (다이얼로그 너비 `max-w-sm` 384px에서 "기준" 열이 너비를 다 가져감)
2. 두 표의 마지막 열에도 `pr-3`이 붙어 오른쪽 끝이 구분선 끝과 맞지 않음 ("누적 점수"·"0점" 열이 안쪽으로 밀림)
3. "기준" 문장이 좁은 열에서 줄바꿈되어 행 높이가 들쭉날쭉함 ("하루 최대 10개분, 삭제되거나 숨겨지면 / 회수돼요")
4. 두 표의 머리글 줄 높이·간격이 서로 다르고, 표 사이 여백이 커서 한 덩어리로 안 보임. 구역 제목이 없어 두 번째 표가 무엇인지 바로 안 읽힘
5. 하단 안내 문구가 마지막 표에 붙어 있고 "삭제처/럼"처럼 어절 중간에서 줄바꿈됨

## 결정 (pm)
- 결정: client가 화면만 수정함 (API·데이터·등급 기준 변경 없음)
  - 다이얼로그 너비를 넓힘 (예: 이 다이얼로그만 `max-w-md` 수준, 360px에서는 화면 너비에 맞춤). 공용 `Modal` 기본값은 바꾸지 않고 너비 옵션을 추가하는 방식 권장
  - 구역 제목 2개 추가: "등급", "점수 얻는 법"
  - 등급 표: 3열 유지, 마지막 열 오른쪽 여백 0으로 구분선과 정렬
  - 활동 표: 열 머리글·값 줄바꿈 금지(`활동`·`점수`), 점수 열은 오른쪽 또는 가운데 정렬 고정폭, "기준"은 남은 너비 사용. 좁은 화면에서 표가 어색하면 활동별 2줄 목록(첫 줄 "글 읽기 +1", 둘째 줄 기준)으로 바꿔도 됨
  - 한글 어절 중간 줄바꿈 방지 (`word-break: keep-all` 등)
  - 하단 안내 문구는 구분선 또는 배경 박스로 표와 분리
  - 다이얼로그 내용이 화면보다 길면 본문만 스크롤(최대 높이 제한), 제목·닫기 버튼은 고정
- 근거: 숫자·문구는 그대로 두고 배치만 정리하면 되는 화면 결함임
- 수용 기준
  - 1440px·360px, 라이트·다크에서 머리글·값이 세로로 꺾이지 않고, 각 표 오른쪽 끝이 구분선과 맞음
  - 어절 중간 줄바꿈 0
  - 360px에서 가로 스크롤 없음, 360×640에서 닫기 버튼이 항상 보임
  - 기존 테스트·빌드 통과
- 후속 작업: client - 수정·배포 후 캡처와 함께 이 파일에 결과 기록 / pm - 공개 사이트 확인 후 종결

## 의견

### client (수정·배포, 2026-11-22)
- 공용 `Modal`
  - `size` 옵션 추가 (`sm` 기본 384px 그대로, `md` 448px). 이 다이얼로그만 `md`, 360px에서는 화면 너비에 맞음(328px)
  - 제목·닫기 줄은 고정하고 본문만 스크롤 (패널 최대 높이 `100dvh - 2rem`). 다른 모달(로그인 안내·확인·탈퇴·관심 태그·태그 편집·세그먼트)도 같은 구조가 되어 긴 내용에서 닫기 버튼이 가려지지 않음. 짧은 모달은 겉모습 변화 없음
- 등급 안내 (`GradeGuideModal`)
  - 구역 제목 "등급"·"점수 얻는 법" 추가, 본문 전체 `word-break: keep-all`
  - 등급 표: 레벨·이름·누적 점수 3열, 모든 칸 줄바꿈 금지, 마지막 열 오른쪽 여백 0 → 구분선 끝과 맞음
  - 점수 규칙: 표 대신 활동별 2줄 목록 (첫 줄 "글 읽기 … +1점", 둘째 줄 기준). 점수는 오른쪽 정렬·줄바꿈 금지. 행 높이 54~55px로 고름
  - 하단 안내는 연한 배경 박스로 표와 분리
  - 숫자·문구·등급 기준은 그대로 (점수 칸만 "+1" → "+1점" 표기)
