# 035. 정렬을 글자 탭으로, 댓글순·좋아요순 추가

- 상태: open
- 제기: pm (사용자 요청)
- 관련: client, server, dba
- 관련 문서: `docs/discussions/033` 정렬 선택, `docs/spec/03-screens.md` 공통 레이아웃·S-16, `docs/spec/02-features.md` F-013·F-072·F-094

## 배경
- 사용자 요청 (2026-11-23): 우측 상단 `[최신순 ▾]` 펼침 선택(033)을, 분야 탭(`전체 · BE · FE …`)처럼 **글자 탭**으로 펼쳐 두고 기준을 늘림
- 사용자 결정
  - 기준: 자유 게시판 `최신순 · 인기순 · 댓글순 · 좋아요순` / 기술 뉴스 `최신순 · 추천순 · 인기순 · 댓글순` / 보안 뉴스 `최신순 · 인기순`
  - 댓글순·좋아요순 기간: 인기순처럼 `24시간 | 7일 | 30일` 선택

## 결정 (pm)
### 화면 (client)
```
전체 · 질문 · 토론 · 공유                 최신순 · 인기순 · 댓글순 · 좋아요순   [✎ 글쓰기]
                                        (인기·댓글·좋아요순이면 아래 [24시간 | 7일 | 30일])
```
- 목록 맨 위 줄: 왼쪽 분야·말머리 글자 탭, **오른쪽 정렬 글자 탭** (분야 탭과 같은 크기·스타일, 선택 = 기본 글자색). 033의 `[최신순 ▾]` 선택 메뉴 제거
- 1단 탭 hover 펼침 메뉴(033)에도 같은 항목 추가 (자유 게시판 4개, 기술 뉴스 4개, 보안 뉴스 2개)
- 모바일·터치: 지금 토글 그룹에 같은 항목 (자유 게시판 4칸·기술 뉴스 4칸). 360px에서 넘치면 가로 스크롤 규칙(1단 탭과 같음)
- 기간 선택은 인기·댓글·좋아요순 사이 이동 시 유지 (기본 7일)
- 비회원 추천순 → 로그인 안내 (031 그대로)
- 주소(제안, 최종은 client·server 합의)
| 화면 | 주소 |
|---|---|
| 자유 게시판 댓글순·좋아요순 | `/community/comments?period=`, `/community/likes?period=` |
| 기술 뉴스 댓글순 | `/tech/comments?period=&field=` |
- 목록: 인기순과 같은 **순위형 상위 20건** (순위 번호 + 해당 수치 표시: 댓글순은 `💬 N`, 좋아요순은 `♡ N` 강조)

### 기준 (server)
- 그 기간에 **발행된** 글 중 댓글 수(`comment_count`) 또는 좋아요 수(`like_count`) 1 이상, 내림차순 상위 20건. 동점은 최신 발행순, 최대 10분 지연(캐시) 허용
  - 자유 게시판: 보이는 글(`VISIBLE`)만, 말머리 필터 적용
  - 기술 뉴스: 블로그 글만(보안·자유 게시판 제외), 분야(`field`) 필터 적용
- 기존 인기 API에 정렬 파라미터를 더할지 새 경로를 둘지는 server 재량. `openapi.yaml` 갱신
- dba: 카운터 정렬 쿼리가 기존 인덱스(기간 범위 스캔 후 정렬)로 충분한지 검토. 새 인덱스·마이그레이션이 필요하면 운영 적용 전 사용자 승인

## 수용 기준
- 세 1단 탭 우측 상단 정렬 글자 탭과 hover 메뉴·모바일 토글이 같은 항목, 선택 상태 일치, 펼침 선택 메뉴 없음
- 댓글순·좋아요순: 기간 전환 동작, 0건 글 제외, 기술 뉴스 댓글순에 보안·자유 게시판 글 없음
- 새 목록 p95 300ms 이하, 360px 가로 넘침 0, 라이트·다크 정상
- 기존 테스트·빌드 통과
