# 036. 1단 탭 hover 펼침 메뉴 삭제

- 상태: open
- 제기: pm (사용자 요청)
- 관련: client
- 관련 문서: `docs/discussions/033`, `035`, `docs/spec/03-screens.md` 공통 레이아웃

## 배경
- 사용자 요청 (2026-11-23): 1단 탭 hover 시 아래로 펼쳐지는 메뉴(033) 삭제. 페이지 안 우측 상단 정렬 글자 탭(035)과 같은 값이라 중복

## 결정 (pm)
- 데스크톱 1단 탭 hover·포커스 펼침 메뉴와 관련 키보드 동작 제거. 1단 탭은 클릭 시 해당 탭의 최신으로 이동하는 글자 탭만 남김
- 정렬 글자 탭(035)·모바일 토글 그룹·주소·비회원 추천 로그인 안내는 그대로
- 쓰지 않게 된 컴포넌트·테스트는 정리

## 수용 기준
- 1440에서 세 1단 탭 hover·Tab 포커스 시 펼침 메뉴 없음, 클릭 시 각 탭 최신으로 이동
- 정렬 글자 탭·360 모바일 토글 그대로, 페이지 오류 0, 테스트·빌드 통과
