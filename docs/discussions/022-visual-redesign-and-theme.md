## 참고 이미지에서 가져올 "느낌" (pm 정리)
- 무채색 중심: 바탕·글자·선이 회색 단계로만 구성, 강조색은 아주 적게(작은 점·링크 정도)
- 상자 대신 여백과 1px 얇은 선으로 영역 구분. 그림자·진한 테두리 없음
- 큰 페이지 제목(굵고 자간 좁음) + 그 아래 글자 탭 줄 + 오른쪽 둥근(알약) 검색창
- 헤더는 얇고 조용함: 로고 왼쪽, 메뉴·로그인 오른쪽, 주요 버튼 하나만 알약형 반전색
- 본문 글자는 읽기 좋은 줄 간격, 링크는 밑줄

## 결정 (pm)

### 1. 테마 토큰과 전환
- 라이트·다크 두 벌의 색 토큰. 화면 코드는 토큰만 사용 (색 직접 지정 금지)
  | 토큰 | 라이트 | 다크 |
  |---|---|---|
  | 바탕 | 거의 흰색 (#fbfbfc 수준) | 거의 검정 (#0b0b0d 수준, 순검정 아님) |
  | 표면(모달·입력) | 흰색 | 바탕보다 한 단계 밝은 회색 |
  | 글자 기본 / 보조 / 흐림 | 진회색 / 중간 회색 / 연회색 | 거의 흰색 / 중간 회색 / 어두운 회색 |
  | 구분선 | 아주 옅은 회색 | 아주 어두운 회색 (바탕과 대비 낮게) |
  | 강조 | 채도 낮은 파랑 1색 | 같은 계열 밝게 |
  | 배지 `NEW`·`인기` | 옅은 배경 + 진한 글자 | 어두운 배경 + 밝은 글자 |
  - 정확한 값은 client가 정하되 본문 글자 대비 WCAG AA(4.5:1) 이상, 보조 글자 3:1 이상
- 전환 버튼: 헤더 오른쪽(로그인 왼쪽), 해·달 아이콘 버튼. `aria-label`("다크 테마로 전환" 등)
  - 처음 접속: 시스템 설정(`prefers-color-scheme`). 버튼으로 바꾸면 브라우저에 저장해 다음 방문에도 유지
  - 첫 화면이 깜빡이지 않게 HTML 로드 직후(렌더 전) 테마 적용
  - 시스템 설정이 바뀌면, 사용자가 직접 고른 적이 없을 때만 따라감
- 적용 범위: 공개 화면 전부 + 로그인·내 정보·관리자(A-01~A-04)까지 전 화면

### 2. onyx-ui 처리
- onyx-ui는 이미 CSS 변수 토큰(`--color-*`)을 쓰고 `data-theme`를 **색상 프리셋**(blue·indigo 등)에 쓰고 있음. 다른 프로젝트 4곳(dinner_picker·korail_macro·salary_calc·severance_calc)이 함께 씀
- 1순위: **DevFeed client 안에서** 다크/라이트 토큰을 덮어써서 해결 (onyx-ui 수정 없음). 명암 전환 속성은 프리셋과 겹치지 않게 별도 속성(예: `data-color-scheme`)
- onyx-ui 컴포넌트에 색이 직접 박혀 있어 토큰으로 덮을 수 없는 곳이 있으면, 그때 `onyx-ui-change` 절차로 수정안·다른 프로젝트 영향 범위를 정리해 **사용자 승인 후** 수정. 다크 토큰 세트 자체를 onyx-ui 공통 기능으로 올릴지는 그 결과를 보고 따로 판단

### 3. 레이아웃·컴포넌트
```
DevFeed                                         ☾   로그인
──────────────────────────────────────────────────────────  (1px)

최신                                         ( 🔍 기술 글 검색… )
최신  추천  인기  기업 블로그  개인 블로그  보안 뉴스
전체 · 백엔드 · 프론트엔드 · AI · 데이터 · 인프라 · 모바일 · 보안
──────────────────────────────────────────────────────────

태그              토스 · 2시간 전  NEW                      ☆
Java  React …     카프카 컨슈머 리밸런싱 줄이기
                  요약 2줄 …
소스 유형          #Kafka #Spring
전체 기업 개인     ─────────────────────────────────────
                  카카오 · 3시간 전  인기
…                 …
```
- 헤더: 높이 낮게, 하단 1px 선. 로고는 글자 로고(지금 이름 `DevFeed` 그대로). 검색창은 헤더에서 **페이지 제목 줄 오른쪽 알약형**으로 이동 (모바일은 헤더 아래 전체 폭)
- 페이지 제목: 현재 탭 이름을 크게(데스크톱 36~40px, 모바일 28px, 굵게, 자간 약간 좁게). 추천은 "추천", 보안 뉴스는 "보안 뉴스"
- 1단 탭: **글자 탭**. 선택 = 기본 글자색(진하게), 나머지 = 보조 글자색. 테두리·배경·밑줄·알약 없음 (021 3차 책갈피형 대체). 마우스 올리면 글자만 진해짐. 키보드 포커스 링은 `:focus-visible`만
- 2단 분야 탭: 1단보다 작은 글자 탭(13~14px), 같은 규칙. 세그먼트 트랙 없음. 1단과는 크기·간격으로 구분
- 탭 영역 아래 1px 선으로 본문과 구분
- 글 목록: 카드 상자 제거 → 위아래 여백 + 글 사이 1px 선. 둥근 모서리·그림자 없음
  - 줄 구성 그대로: 소스·시간·배지 / 제목(굵게, 2줄) / 요약(보조색, 2줄) / 태그(흐린 색) / 썸네일(오른쪽, 작은 둥근 모서리 유지)
  - 마우스 올리면 행 배경이 아주 옅게 바뀜. 읽은 글은 지금처럼 흐리게
  - 보안 뉴스의 날짜 구분선은 참고 이미지처럼 **왼쪽 작은 점 + 날짜** 형식
- 사이드바: 상자 제거, 여백과 작은 섹션 제목(보조색 대문자 느낌의 작은 글자)으로 구분. 칩은 얇은 테두리 알약 유지, 선택 칩은 반전색(라이트=진회색 바탕 흰 글자, 다크=흰 바탕 검은 글자)
- 버튼: 주요 버튼 1종만 반전색 알약(로그인·적용 등), 나머지는 테두리 없는 글자 버튼 또는 얇은 테두리
- 모달·하단 시트(S-12): 표면색 + 1px 테두리, 그림자는 다크에서 거의 없음
- 글꼴: 지금 글꼴 유지 가능. 바꾼다면 한글·영문 모두 고른 무료 웹폰트(예: Pretendard)까지만, 참고 사이트 전용 글꼴은 쓰지 않음
- 강조색은 링크·포커스 링·`NEW` 점·선택 상태 일부에만. 넓은 면적에 쓰지 않음

### 4. 하지 않는 것
- 참고 사이트의 로고·브랜드명·문구·카드 그래픽·고유 배치를 그대로 옮기지 않음 (느낌만 참고)
- 다크 테마를 "색 반전 필터"로 구현하지 않음 (이미지·썸네일 색 왜곡)
