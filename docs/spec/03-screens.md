# 03. 화면 목록과 흐름

- 작성: pm
- 상태: 초안 v1 (2026-11-19)
- 와이어프레임은 데스크톱 기준 텍스트 표현. 모바일은 사이드바를 상단 필터 칩/드로어로 접음

## 화면 흐름

```
[게스트]
S-01 홈 ──검색──▶ S-04 검색 결과
  │  ├─카드 클릭──▶ (원문 새 탭, 조회 기록)
  │  ├─인기 탭──▶ S-03
  │  └─북마크/추천 클릭──▶ S-05 로그인 ──가입──▶ S-06
  │
[회원가입]
S-06 ──완료──▶ S-07 온보딩 ──완료/건너뛰기──▶ S-02 추천 피드

[회원]
헤더 탭: 최신(S-01) | 추천(S-02) | 인기(S-03)
프로필 메뉴: 북마크(S-08) | 읽은 기록(S-09) | 설정(S-10) | 로그아웃

[관리자]
A-01 ──소스 클릭──▶ A-02 ──수정──▶ A-03
  ├─소스 추가──▶ A-03
  └─태그 사전──▶ A-04
```

## S-01 홈 (최신 피드)

```
┌ 필터 ─────────┐ ┌ 피드 ───────────────────────────────────────┐
│ 태그           │ │ [필터 칩: Kafka ✕] [기업 ✕]        초기화    │
│ [검색 태그..]   │ │ ┌───────────────────────────────────────┐  │
│ ☑ Kafka       │ │ │ [로고] 토스 기술블로그 · 2시간 전       ☆ │  │
│ ☐ React       │ │ │ 카프카 컨슈머 리밸런싱 줄이기     [썸네일] │  │
│ ☐ Kubernetes  │ │ │ 요약 2~3줄 ...                          │  │
│ 더보기         │ │ │ #Kafka #Spring                         │  │
│ 소스 유형       │ │ └───────────────────────────────────────┘  │
│ ◉ 전체 ○기업   │ │ ┌ (읽은 글은 흐리게) ──────────────────────┐  │
│ ○ 개인         │ │ └───────────────────────────────────────┘  │
│ 소스           │ │            ... 무한 스크롤 / 로딩 스켈레톤 ...  │
│ [검색 소스..]   │ └───────────────────────────────────────────┘
└──────────────┘
```
- 상태: 로딩(스켈레톤 카드), 빈 결과("조건에 맞는 글이 없음" + 필터 초기화), 오류(재시도 버튼)
- ☆ 클릭: 게스트면 로그인 유도 모달, 회원이면 즉시 토글

## S-02 추천 피드

```
┌ 피드 ─────────────────────────────────────────────────────┐
│ 나를 위한 추천           관심 태그: #Kafka #MySQL  [편집]     │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ 💡 추천 이유: Kafka 관심 태그, 최근 읽은 글과 비슷함        │ │
│ │ [글 카드 - S-01과 동일]                                 │ │
│ └──────────────────────────────────────────────────────┘ │
│ ...                                                       │
└───────────────────────────────────────────────────────────┘
```
- 선호 데이터 없음: "관심 태그를 고르면 더 정확해짐" 안내 + 인기 글 표시 + S-07 이동 버튼

## S-04 검색 결과

```
┌ 필터 ─────────┐ ┌ 결과 ───────────────────────────────────────┐
│ 기간           │ │ "리밸런싱" 검색 결과 132건   정렬 [관련도 ▾]  │
│ ○1주 ○1개월    │ │ [카드: 제목·요약에서 **리밸런싱** 강조]        │
│ ○1년 ◉전체     │ │ ...                                          │
│ 태그 / 소스     │ │ [ ◀ 1 2 3 4 5 ▶ ]                            │
└──────────────┘ └───────────────────────────────────────────┘
```
- 결과 없음: "검색 결과가 없음. 철자를 확인하거나 다른 키워드를 써보셈" + 인기 태그 칩
- 검색어 1자 입력 시 검색 버튼 비활성 + 안내 문구

## S-05 로그인 / S-06 회원가입

```
┌──────────────────────────┐   ┌──────────────────────────┐
│ 로그인                    │   │ 회원가입                   │
│ 이메일 [.............]    │   │ 이메일   [.............]  │
│ 비밀번호 [.............]   │   │ 비밀번호 [.............]  │
│ [ 로그인 ]                │   │ 비밀번호 확인 [..........] │
│ 계정이 없음? 회원가입       │   │ 닉네임   [.............]  │
└──────────────────────────┘   │ [ 가입하기 ]               │
                               └──────────────────────────┘
```
- 오류 표시: 필드 하단 인라인 메시지, 로그인 제한 시 남은 시간 표시
- 로그인 후 원래 보던 화면으로 복귀

## S-07 관심 태그 온보딩

```

[검색 태그.......]
분류: 백엔드 | 프론트엔드 | 데이터 | 인프라 | AI | 모바일
[Kafka] [Spring] [MySQL✓] [Redis] [React✓] [Kubernetes✓] ...
                                   선택 3/10   [건너뛰기] [완료]
```

## S-08 북마크 / S-09 읽은 기록

```
북마크 (152)                     태그 [전체 ▾]
[글 카드 + 저장일]  ★
...

읽은 기록                         [전체 삭제]
2026-11-19
  [글 카드 컴팩트]  ✕
2026-11-18
  ...
```
- 전체 삭제는 확인 모달 필수

## S-10 설정

```
프로필:   닉네임 [.......] [저장]
관심 태그: #Kafka ✕ #MySQL ✕ [+ 추가]   (3개일 때 ✕ 비활성 + "최소 3개 필요" 안내)
계정:     [로그아웃]  [회원 탈퇴]
```
- 회원 탈퇴: 삭제되는 데이터 안내 + 비밀번호 재입력 모달
