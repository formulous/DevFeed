## 문구 원칙 (024)
- 화면에 보이는 문구는 **해요체** (예: "계정이 없으신가요?", "조건에 맞는 글이 없어요"). 버튼·탭·라벨 같은 짧은 명사는 그대로
- 이 문서의 따옴표 속 화면 문구 중 음슴체로 적힌 예시는 내용만 참고하고, 실제 화면은 해요체로 씀
- 서버 오류 메시지 중 화면에 그대로 보이는 것도 해요체

## 공통 레이아웃

```
┌──────────────────────────────────────────────────────────────┐
│ f. formulous [ 검색어 입력 ........  🔍 ]     로그인 | 프로필 ▾ │
│ 자유 게시판   기술 뉴스   보안 뉴스          (031, 032, 033)  │ ← 1단 탭
├──────────────────────────────────────────────────────────────┤
│ [ 최신 | 추천 | 인기 ]   (보안 뉴스는 [ 최신 | 인기 ])            │ ← 내부 탭 (031)
│ 전체 · BE · FE · AI · Data · Infra · Mobile · Security         │ ← 2단 분야 탭
├──────────────┬───────────────────────────────────────────────┤
│ 사이드바       │ 본문                                            │
│ (필터)        │                                               │
└──────────────┴───────────────────────────────────────────────┘
```

- 사이드바(필터)는 스크롤 없는 요약 패널: 인기 태그 12개 칩, 소스 유형 세그먼트, 선택된 소스 칩 + 최근 30일 글이 많은 소스 5개(019). 전체 목록은 "전체 ›"로 여는 선택 창(S-12)에서 고름. `sticky` 독립 스크롤은 낮은 화면용 안전장치로만 유지 (016, 017)

- 디자인 개편(022): 무채색 중심, 상자 대신 여백·1px 선. 라이트/다크 테마(시스템 설정 기본, 헤더 ☾/☀ 버튼으로 전환·기억). 페이지 제목 크게 + 오른쪽 알약형 검색창(hero). hero는 탭 6개 화면·검색 화면에만, 내 정보·관리자·개인정보 화면은 헤더 검색 아이콘. 관리자 표·폼·설정·로그인은 얇은 테두리 상자 유지
- 1단 탭 순서·펼침 메뉴(033): `자유 게시판 · 기술 뉴스 · 보안 뉴스`(커뮤니티 → 자유 게시판, 주소 그대로). 데스크톱(hover 가능)은 목록 우측 상단 정렬 **글자 탭**(1단 탭 hover 펼침 메뉴는 036에서 삭제)(035: 자유 게시판 `최신순 · 인기순 · 댓글순 · 좋아요순`, 기술 뉴스 `최신순 · 추천순 · 인기순 · 댓글순`, 보안 뉴스 `최신순 · 인기순`, 선택 메뉴 대체), 하위 탭 토글 그룹 없음. 모바일·터치는 아래 토글 그룹 유지. 세부 `docs/discussions/033`
- 1단 탭·내부 탭(031, 032): 1단은 기술 뉴스·보안 뉴스·커뮤니티 3개, hero 제목은 1단 탭 이름. 내부 탭은 본문 맨 위 줄의 작은 세그먼트(트랙형)로 분야 글자 탭과 구분, 360px 한 줄. 1단 이동 시 해당 탭의 최신. 게스트 추천 클릭 시 로그인 유도 모달. 주소·넘김은 `docs/discussions/031`
- 1단 탭(022, 021 책갈피형 대체): 글자 탭. 선택 = 기본 글자색, 나머지 = 보조 글자색, 테두리·배경·밑줄 없음. 키보드 포커스 링은 `:focus-visible`만. 360px은 가로 스크롤(양끝 흐림), 활성 탭 자동 노출
- 글 목록(022): 카드 상자 없이 글 사이 1px 선. 사이드바도 상자 없이 섹션 제목·여백으로 구분
- 2단 분야 탭(021, 022, 023): 기술 뉴스 최신·인기에서만 (내부 탭 아래 줄, 031). 라벨 `전체 · BE · FE · AI · Data · Infra · Mobile · Security`(BE·FE는 툴팁·스크린리더 풀네임). 1단 탭 아래 1px 구분선 **아래**(본문 맨 위 줄)에 둠, 분야 탭 아래 추가 구분선 없음. 1단보다 작은 글자 탭(트랙·알약 없음), 기본 `전체`, URL `?field=backend|frontend|ai|data|infra|mobile|security`(잘못된 값은 `전체`). 추천·보안 뉴스 탭에는 없음
- 탭 이동 시 분야는 유지, 태그·소스 필터는 초기화 (탭마다 소스 범위가 다름)
- 글 항목 반응 줄(026, F-080·F-081): 항목 맨 아래 줄 오른쪽 `♡ N  💬 N`. S-01·S-02·S-03·S-04·S-08·S-14·S-15 공통, S-09 제외. 항목 본문 클릭은 원문 이동, 반응 줄·댓글 영역 클릭은 이동 없음. `💬` 클릭 시 항목 바로 아래 댓글 영역 펼침(와이어프레임 `docs/discussions/026`)
- 모바일 다이얼로그(039): 짧은 안내·확인은 가운데 작은 창(좌우 24px), 긴 내용(선택 창·등급 안내·관심 태그·관리자 폼)은 아래 시트(최대 85dvh, 본문만 스크롤, 하단 버튼 고정). `docs/discussions/039`
- 프로필 카드(029, F-082): 기술 뉴스 3개·보안 뉴스 2개 내부 탭·검색 화면(031) 좌측 열 맨 위(필터·출처 사이드바 위, 좌측 열 없는 화면은 새로 둠). 회원은 자동 아바타·닉네임·등급·진행 막대·좋아요/댓글/읽은 글/북마크 수, 게스트는 로그인 안내 카드. `lg` 미만은 숨기고 헤더 프로필 메뉴에 한 줄. 와이어프레임 `docs/discussions/029`
- 좌우 광고(025, F-060): 1440px 이상, 기술 뉴스 3개·보안 뉴스 2개 내부 탭·검색 화면(031)에서만 `[좌 광고 160] [사이드바+본문] [우 광고 160]`. 광고는 헤더 아래 `sticky`, 본문 영역 축소 허용. 그 외 화면·1440px 미만은 광고 없음

## S-01 홈 (최신 피드)

```
┌ 필터 ─────────┐ ┌ 피드 ───────────────────────────────────────┐
│ 태그    전체 › │ │ [필터 칩: Kafka ✕] [기업 ✕]        초기화    │
│ [Kafka✓][React]│ │ ┌───────────────────────────────────────┐  │
│ [Java][Rust].. │ │ │ [로고] 토스 기술블로그 · 2시간 전       ☆ │  │
│ (인기 12개 칩)  │ │ │ [NEW][인기] 카프카 컨슈머 리밸런싱 [썸네일] │  │
│ 소스 유형       │ │ │ 요약 2~3줄 ...                          │  │
│[전체|기업|개인] │ │ │ #Kafka #Spring                         │  │
│ 소스    전체 › │ │ └───────────────────────────────────────┘  │
│ [토스 ✕]       │ │ ┌ (읽은 글은 흐리게) ──────────────────────┐  │
│ (최근 활발 5개) │ │ └───────────────────────────────────────┘  │
│ 선택 2 · 초기화 │ │            ... 무한 스크롤 / 로딩 스켈레톤 ...  │
│               │ └───────────────────────────────────────────┘
└──────────────┘
```
- 상태: 로딩(스켈레톤 카드), 빈 결과("조건에 맞는 글이 없음" + 필터 초기화), 오류(재시도 버튼)
- ☆ 클릭: 게스트면 로그인 유도 모달, 회원이면 즉시 토글
- 배지(F-014, 020): 소스 줄 시간 오른쪽 작은 텍스트 배지 (좁은 화면은 소스 이름 말줄임). `NEW` = 발행 24시간 이내, `인기` = 7일 인기 상위 20건. S-02·S-04·S-08 카드 동일, S-03은 `NEW`만, S-09 컴팩트 카드는 없음

## S-05 로그인 / S-06 회원가입 (027 개편)

```
 f. formulous                                         ☾
                      ◆
                   formulous에 로그인
              [ 🔑  패스키로 로그인        ]
              [ ✉  이메일로 계속하기       ]
              계정이 없으신가요? 회원가입
                                  개인정보 안내
```
- Linear 느낌: 화면 정중앙 폭 320~360px 스택, 카드 상자 없음, 상단 로고·테마 버튼만(탭·검색·푸터 숨김), 옅은 방사형 배경 빛, 44px 버튼
- "이메일로 계속하기" → 같은 자리에서 이메일·비밀번호·[로그인] + "← 다른 방법으로 로그인". 이메일 입력칸은 패스키 자동완성 지원
- 패스키 미지원 브라우저: 패스키 버튼 숨기고 이메일 입력 상태로 시작
- 회원가입(S-06): 같은 레이아웃, 이메일·비밀번호(보기 버튼)·닉네임 → [가입하기] → "다음부터 지문이나 얼굴로 바로 로그인할까요?" [패스키 만들기] [나중에] → S-07
- 오류 표시: 입력칸 아래 한 줄, 로그인 제한 시 남은 시간. 패스키 취소는 오류 아님
- 로그인 후 원래 보던 화면으로 복귀
- 상세 와이어프레임: `docs/discussions/027`

## S-07 관심 태그 온보딩

```
관심 있는 기술을 3개 이상 고르셈 (최대 10개)
```
